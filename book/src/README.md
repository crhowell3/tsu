# tsu

tsu is a modal, terminal-based text editor. It is inspired by helix, another text editor implemented
in the Rust programming language. It is vimlike, fully configurable, and will eventually have
support for custom plugins.

## Contributing

tsu is free and open source. You can find the source code as well as report issues and create
feature requests on [GitHub](https://github.com/crhowell3/tsu).
