## Build from source

Clone the tsu GitHub repository and build with `cargo`.

Requirements:

- [Rust toolchain](https://www.rust-lang.org/tools/install)
- [Git version control](https://git-scm.com/)

```shell
# Clone the repo
git clone https://github.com/crhowell3/tsu.git

cd tsu

# Run tests
cargo test -q

# Install
cargo install --path .
```
